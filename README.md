# HR Attirition Dashboard

## Overview
This project presents an interactive HR Attirition Dashboard built using Microsoft Excel.
It analyzes employee attirition patterns across department , job roles , and various influencing factors such as overtime , worklifr balance , and education

## Tools & Techniques Used 
- Microsoft Excel 
- pivot tables
- pivot charts
- data cleaning(basic preprocessing)
- Data Analysis

## Dashboard Features
- Total Employees , Males & females distribution
- Department - wise attirition
- Job role - wise attirition
- Work-life balance & travel impact
- Education & Performance-based attirition
- Overtime impact in Attirition
- Gender-wise Attirition Rate

  ## Key Insights
-  Highest attrition is observed in the Research & Development department
-  Certain job roles (like Sales Executive & Laboratory Technician) show higher attrition
-  Employees with frequent travel and poor work-life balance have higher attrition
-  Overtime employees are more likely to leave
-  Some education fields (like Life Sciences & Medical) show noticeable attrition trends

##How to Use
1. Download the repository
2. Open HR_Dashboard.xlsx in Microsoft Excel
3. Navigate to the Dashboard sheet
4. Use filters/slicers (if available) to explore data
5. Check Backend_Data sheet for pivot tables

⚠️ Important Notes
- Pivot tables are used as backend and should not be deleted
- Dashboard is connected to pivot tables for dynamic updates
- Ensure data consistency before making changes
